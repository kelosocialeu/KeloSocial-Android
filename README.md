# Kelo Social Android

Application Android officielle de Kelo Social.

- Site : https://kelosocial.eu
- PDS : https://pds.kelosocial.eu
- Protocole : AT Protocol
- Langage : Kotlin
- UI : Jetpack Compose

## Objectif

Construire une application Android native, rapide et adaptée aux téléphones et tablettes, avec l'expérience Kelo Social.

## Développement

Ouvrir le projet dans Android Studio, synchroniser Gradle puis lancer la configuration `app`.

## Sécurité

Aucun secret, token privé ou identifiant d'administration ne doit être commité dans ce dépôt.
